# 全屏音乐样式小样（存档）

2026-10-18 做的全屏音乐样式小样，网页实现，用来评估效果，暂不接入 Glance。Glance 的全屏音乐仍用原来的“流烟”。

在线版（仅主人可见）：https://claude.ai/artifact/Kv6AtQvmEsC7fpoZRGHbZn

## 三种样式

- **海报**：复古未来风格。黄昏渐变天空，地平线上一轮被横条切开的太阳，太阳在地面有倒影，前方飘着细云。三层山，最远一层用霓虹线勾边。地面是透视网格，每一拍有一道亮线从地平线冲到眼前。封面缩成左上角的唱片封套，唱片随播放转动。画面加扫描线和暗角。歌词是条纹大字：整句从两侧交错滑入，唱到的字条纹合拢成实心，带两层彩色残影。
- **波普**：漫画分格加粗黑描边，黄底红色网点（随低音变大）。封面做成沃霍尔式的四格撞色印刷，每小节换一次颜色。歌词在对话气泡里逐字弹出，下一句在旁白框里，重要时刻炸出 POP!、WOW! 这类爆炸字。
- **文字 PV**：参考 JIZURA。一句一个镜头（长句两个），每个镜头按段落从下面几组里选一种：
  - 排版 10 种
  - 背景 14 种
  - 文字处理 11 种
  - 镜头运动 9 种
  - 转场 9 种
  - 装饰 7 种

  同一段落只用少数几种，同一句副歌每次画面完全一样，段落第一个镜头固定是急推加闪白。动作按每秒 12 帧画。整句一开始就落定，没唱到的字半透明，唱到时变实，屏幕下方始终有整句字幕。

三种样式共用的部分：
- 颜色全部从封面自动取：主色由聚类得出，强调色取自最鲜艳的那批像素。
- 节拍事先从歌曲分析得出。频谱和响度实时从播放的声音里听。
- 歌词用网易云的逐字时间。
- 切换样式时音乐不中断。
- 控件仿照 Glance 当前的全屏控件。

已评估并放弃的方向：剪纸色块（太乱，收敛后也不好看）、深空（流烟噪声做的星云像烟，日食版也未采用）。

## 重新生成

仓库里只有代码，不含歌词、封面和歌曲，这些归版权方所有。

需要 numpy、Pillow、imageio-ffmpeg。用网易云的歌曲编号和本机的 mp3 生成：

```
python prepare.py 229271 "D:\Downloads\如果的事.mp3" D:\tmp\fullscreen "IF" "FAN WEI QI & ANGELA CHANG"
cd D:\tmp\fullscreen
python -m http.server 8766
```

然后打开 http://127.0.0.1:8766/index.html 。

脚本还会检查歌词时间和这份 mp3 的偏差。偏差超过 0.08 秒时，会自动平移歌词时间。
