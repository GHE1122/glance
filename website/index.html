功能

平时看不见，想看时一推就有

不想看时不占桌面、不挡窗口，也不用为了看一眼温度切出游戏、打开任务管理器；想一直看着，就撕一块放在桌面上。

  • 推一下屏幕边缘就出来

    鼠标推到屏幕右边缘，面板滑出；移开就收回。要稍微用点力推才会打开，贴边滚动、拖窗口都不会误触。推哪一边、推多大力都能改。每条边还可以放不同的组件，比如右边放监控、左边放工作台，在设置的“布局”里拖过去就行。也可以按 Ctrl+Alt+G，在鼠标旁边打开。

  • 三种外观，深浅随你

    记录纸、磨砂玻璃、Windows 11。磨砂玻璃的边缘会折射背后的桌面，Windows 11 用的是和开始菜单一样的亚克力材质。浅色、深色，或者跟着壁纸亮度自动切换。

  • 真实的温度、功耗和风扇

    CPU 每个 CCD 的温度和封装功耗，显卡的功耗和风扇，每根内存条的温度，主板各处的温度和风扇转速，都直接从硬件传感器读出来。

  • 想看什么就留什么

    每个模块、模块里的每一项都能单独开关。进程可以按 CPU、内存、读写或 GPU 排序；嫌图表占地方，关掉就只剩数字，面板更紧凑。

  • 玩游戏时，看得到帧率

    全屏游戏运行时，面板最上面自动多出"游戏"一栏：帧率、1% low、帧时间图，游戏自己占的 CPU、GPU 和显存，显卡有没有撞上功耗墙。帧率来自 Windows 自带的事件跟踪，不注入、不碰游戏进程。

  • 悬浮窗，常驻在角落

    几项读数浮在屏幕上，一直显示，或者只在玩游戏时出现。卡片或横条两种布局，放在一块半透明的玻璃上，按背后画面的明暗自动变深变浅，字始终看得清。拖到哪放在哪，拖边角改大小，显示什么、按什么顺序由你定。

  • 撕一块放在桌面上

    把面板从屏幕边缘拖开，它就变成留在桌面上的小组件。拖边角改大小，内容跟着空间重新排版，各种形态之间平滑过渡。拖到屏幕边上会提示停靠位置，松手就贴上去；甩出屏幕就收起。重启后还在原处。

  • 躺下之后，用手机关屏关灯

    手机上装一个小 APP，扫码配对，就能给电脑关屏幕、关机箱灯、调音量和亮度、切歌，顺便看一眼温度；“夜间模式”一键全关，电脑继续下载。只在你家的局域网里工作，不经过任何服务器。下载手机 APP

工作台和音乐

不只是监控

0.4 起，Glance 多了两个组件：放随手要用的东西的“工作台”，和跟着歌词走的“音乐”。和监控一样，可以放在任意一条屏幕边缘，也能拖出来放在桌面上。

  • 中转站：先放这儿，用时再拖走

    文件、图片、文字、链接，拖进中转站或者粘贴进来，临时放着，要用的时候再拖到别的程序里。“最近复制”记下剪贴板里来过的东西，可以暂停。“最近文件”列出刚下载、刚保存的文件。双击打开，右键固定，放久了会自己清走。

  • 便签，写的就是 Markdown

    每条便签都是“文档\Glance 便签”里的一个 .md 文件，换个编辑器也能打开。标题、加粗、待办方框、链接都按排好的样子显示，方框点一下就勾上，链接点一下就打开。只有光标所在的那一行才露出 Markdown 符号。便签可以贴到桌面上，直接在上面写。

  • 快捷启动

    常用的程序、文件、文件夹和网址排在一起，点一下就开。可以从开始菜单的全部程序里挑，从最近用过的里加，也可以直接拖进来，拖动就能调整顺序。

  • 音乐：歌词跟着唱

    正在播放的歌：封面、进度、音量，歌词一句一句跟着走，有逐字时间的会一个字一个字亮起来。网易云音乐、QQ 音乐、酷狗和 LRCLIB 一起找歌词。拉大是一张转着的唱片和频谱，也可以全屏。

常见问题

安装和使用

运行安装包时，弹出“Windows 已保护你的电脑”，怎么办？

点提示里的 更多信息，再点 仍要运行 就行。

这是 Windows SmartScreen 对下载量还不多的新软件的例行提示，不代表安装包有问题。Glance 的安装包带有作者的数字签名（发布者：Weiyi Shi，通过微软的 Artifact Signing 签发）：右键安装包 → 属性 → 数字签名，就能看到。下载的人多了，这个提示会慢慢消失。

请只从本页、GitHub 或 Gitee 下载。别人转发的安装包，签名对不上就不要运行。

第一次打开时为什么要管理员权限？

读取 CPU 温度、功耗和风扇转速需要直接访问硬件，Glance 通过安装时一并装好的 PawnIO 驱动来读（它同样有签名，并且开源）。只在第一次启动时询问一次，之后打开不再弹窗，也可以设为开机自动启动。

装好了，面板在哪？怎么打开？

Glance 启动后不会弹出窗口，它待在两个地方：

  • 屏幕右边缘：鼠标往右边缘推一下，面板滑出；移开鼠标就收回。
  • 任务栏右下角的托盘：鼠标悬停能看到简要读数，右键打开设置。图标可能收在 ^ 里。

任何时候按 Ctrl+Alt+G 都能打开或收起。想让面板一直显示，点面板底栏的图钉；固定后还能按住面板把它拖到任何位置，拖边角调整大小。推哪一边、推多大力、面板出现在哪，都可以在 设置 → 呼出 里改。

玩游戏时推屏幕边缘，面板没出来？

多半是游戏开着 独占全屏。这种模式下游戏独占整块屏幕，别的程序（包括 Glance）都盖不上去。

在游戏的 画面 / 显示 设置里，把显示模式改成 无边框窗口（也可能叫“窗口化全屏”“无边框全屏”或 Borderless），面板就能正常滑出了。在 Windows 10 / 11 上，无边框和独占全屏的帧数通常差别不大。

会不会拖慢电脑、影响游戏帧数？

几乎感觉不到。面板收起时，Glance 约占 110 MB 内存，CPU 占用约为单个核心的 1%。读数默认每秒刷新一次，想更省可以在设置里调慢。

会收集我的数据吗？

不会。不用注册，没有广告，不上传任何东西。Glance 唯一的联网，是每天向 GitHub 和 Gitee 问一次有没有新版本，这项检查在设置里可以关掉。代码全部开源，谁都可以查。

我的电脑能用吗？

Windows 10 和 11 的 64 位系统都能用。CPU 支持 AMD Ryzen 和 Intel Core；主板传感器支持 ITE 和 Nuvoton 芯片；NVIDIA 和 AMD 独立显卡能显示功耗。笔记本的主板温度由笔记本自己的控制器管着，暂时显示不了；风扇目前只有华硕笔记本能显示；电池的充放电功率和健康度所有笔记本都能看。目前没有 Mac 版。

读数不对或少了什么，欢迎到 Gitee 或 GitHub 反馈：在 设置 → 诊断信息 里点“复制”，直接粘贴进去就行，里面不含路径和用户名。

怎么更新？

Glance 每天自己检查一次，有新版本时托盘会提示，在设置里点“更新”即可。它只会运行签名与自己一致的安装包。也可以随时来这里下载新版，直接覆盖安装，设置会保留。

怎么卸载？

和其他软件一样：Windows 设置 → 应用 → 已安装的应用，找到 Glance 卸载；或者在 Glance 的 设置 → 系统 → 卸载 Glance。

卸载会删除程序、它的计划任务和设置，并询问要不要一起卸载 PawnIO 驱动。别的监控软件也可能在用这个驱动，不确定的话可以留着。

0.1.72026 年 10 月 6 日最新

修复

  • 面板每次打开的形状保持一致。有些读数会随硬件状态时有时无（比如核显空闲时频率停了、风扇停转、传感器偶尔漏读、电池一时没有回应），以前每出现或消失一项，面板就多一行或少一行，可能在两栏和三栏之间来回切换。现在最近几分钟内读到过的项目会一直保留位置，读不到时显示“—”，图表在那里断开，而不是掉到 0。感谢小红书上发视频反馈的朋友。
  • 虚拟显示器（Parsec、串流软件等）的适配器不再被当成第二张显卡，显示一条一直为 0 的显卡。

改进

  • 更新也会从 Gitee 镜像获取，GitHub 连不上时也能收到。Glance 用连得上的那一边，并且仍然只运行签名与自己一致、版本与宣称一致的安装程序。检查更新失败后一小时内重试，不再等到第二天。
  • 设置里“检查更新”下方显示当前版本，glance.exe 的文件属性里也能看到版本号。
  • 如果面板打开期间形状发生变化，Glance 会记进日志，“复制诊断信息”里会带上。

升级：0.1.4 到 0.1.6 会通过 GitHub 提示这次更新。如果你那边连不上 GitHub，请从镜像下载安装程序：https://gitee.com/lulu-loopp/glance/releases 。设置会保留。

0.1.62026 年 10 月 6 日

修复

  • 面板打开后不再变来变去。有些读数会时有时无（比如显卡风扇停转又启动、传感器偶尔漏读一次），面板之前每次都会重新排版，在缩放比例较高的屏幕上可能在不同栏数或缩放之间来回切换。现在面板会保持打开时的形状：栏数不变，打开期间各部分只会变高、不会变矮。感谢小红书上反馈这个问题的朋友。

升级：0.1.4 及以后的版本会自己提示这次更新；更早的版本请运行一次本安装程序，设置会保留。

0.1.52026 年 10 月 6 日

变更

  • 托盘图标的悬停读数改为分栏对齐：名称在左，占用和温度各自对齐，中英文都一样。

新增

  • 日志文件 glance.log，位于设置旁边的 %APPDATA%\dev.weiyi.glance。记录崩溃、显卡设备丢失、设置保存失败、更新的每一步（发现新版本、下载、被拒绝及原因、启动安装程序）、PawnIO 驱动缺失、快捷键被占用。只保留最近 200 行，重复出现的消息只计数不重复写入，路径中的用户名一律写成 <user>。“设置 → 诊断信息”现在会附上最近的日志；卸载时日志随设置一起删除。

升级：0.1.4 会自己提示这次更新（一天之内，或下次启动时）；更早的版本请运行一次本安装程序，设置会保留。

0.1.42026 年 10 月 6 日

新增

  • 自动更新：Glance 每天向 GitHub 查询一次是否有新版本（设置 → 系统 → 检查更新，默认开启，可以关闭；这是 Glance 唯一的联网行为）。有新版本时托盘会提示，设置中会出现更新按钮；Glance 下载安装程序后，只有确认其签名与当前 Glance 出自同一发布者，才会运行它。
  • Ctrl+Alt+G：在鼠标所在位置打开面板，再按一次收起（设置 → 呼出）。
  • 固定面板：点面板底栏的图钉，面板会一直显示，方便边做别的事边看；固定后可以按住面板拖到任何位置（包括另一块屏幕），拖边角调整大小。
  • 托盘悬停读数：鼠标悬停在托盘图标上，会显示 CPU、显卡和内存的简要读数。
  • 过热提醒（默认关闭；设置 → 数据）：CPU 或显卡持续 30 秒达到温度警示值时，托盘会弹出提醒。
  • 诊断信息（设置 → 系统 → 复制）：把 Glance 识别到的硬件和读数情况复制到剪贴板，可直接粘贴到 issue，不包含路径或用户名。

修复

  • 安装在 Program Files 以外（例如 D:\Glance）时，再次运行安装程序会更新原位置；之前会默认装到 Program Files，可能多出一份。
  • 磨砂玻璃边缘延伸到背景范围之外时不再发暗。

升级：从 0.1.3 及更早版本升级，请运行一次本安装程序覆盖安装，设置会保留。此后 Glance 会自己提示更新。
